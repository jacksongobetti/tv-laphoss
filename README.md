# tv-laphoss

Apresentação em loop da TV da recepção da Laphóss Estética Avançada.

- Endereço na TV: https://jacksongobetti.github.io/tv-laphoss/#tv
- Pré-visualização com controles: https://jacksongobetti.github.io/tv-laphoss/

A página confere a cada 5 minutos se existe uma versão nova e se recarrega sozinha.
Às 6h faz uma recarga de manutenção (só se a internet estiver ok).
